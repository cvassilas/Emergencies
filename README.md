# ICU Emergencies (Android)

WebView wrapper around the ICU/PICU emergency companion (`app/src/main/assets/index.html`).
Everything runs on the device; no network calls are made by the app.

Build: pushing to `main` runs the **build-apk** workflow. Download `emergencies-debug-apk` from the run's Artifacts.
Export writes `.txt` files to the phone's Downloads folder.
